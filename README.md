# نظام ERP لإدارة معرض سيارات — الإمارات العربية المتحدة

نظام يربط **المبيعات** و**المشتريات** و**المخازن** و**الحسابات** في قاعدة بيانات واحدة، بالدرهم الإماراتي (AED) وضريبة القيمة المضافة 5%.

## التشغيل (3 أوامر)

المتطلب الوحيد: **Node.js 22.13 أو أحدث** (لا حاجة لـ `npm install` ولا لتثبيت أي قاعدة بيانات).

```bash
npm run seed     # إنشاء قاعدة البيانات + بيانات تجريبية إماراتية
npm start        # تشغيل النظام
# ثم افتح:  http://localhost:5000
```

| المستخدم | الدور | كلمة المرور المحلية التجريبية |
|---|---|---|
| `admin` | مدير النظام | `Demo@2026` |
| `sales1` | مبيعات | `Demo@2026` |
| `purchasing1` | مشتريات | `Demo@2026` |
| `accountant1` | محاسب | `Demo@2026` |
| `warehouse1` | أمين مخزن | `Demo@2026` |

هذه بيانات الدخول للتشغيل المحلي فقط. يستخدم النشر على Render كلمة مرور عشوائية من `DEMO_PASSWORD` كما هو موضح أدناه.

> غيّر كلمات المرور من «إعدادات الشركة» قبل أي استخدام فعلي، وحدّث بيانات الشركة والرقم الضريبي (TRN) من نفس الصفحة.

أوامر أخرى: `npm run reset` (مسح القاعدة وإعادتها) · `npm test` (51 اختباراً تلقائياً).

## النشر على Vercel

يستضيف Vercel الواجهة الأمامية، بينما يستضيف Render خادم Node.js وقاعدة SQLite على قرص دائم. ملفا `vercel.json` و`render.yaml` يضبطان توجيه الطلبات وإعداد الخادم.

1. في Render اختر **New → Blueprint**, اربط المستودع `2sama0/erp-uae`، ثم أنشئ الخدمة من `render.yaml`. تتطلب قاعدة البيانات قرص Render دائمًا وخطة خدمة مدفوعة؛ لا تحذف القرص أو تعِد إنشاءه بعد بدء استخدام النظام.
2. انتظر حتى تصبح خدمة `erp-uae-api` جاهزة. عنوانها الافتراضي هو `https://erp-uae-api.onrender.com`. إذا أعطاك Render عنوانًا آخر، حدّث وجهة `/api/:path*` في `vercel.json` إلى عنوان خدمتك ثم ادفع التغيير إلى GitHub.
3. في إعدادات مشروع Vercel اترك **Root Directory** على جذر المستودع. ينشر `vercel.json` مجلد `frontend` تلقائيًا. أعد نشر المشروع بعد تجهيز خدمة Render.
4. اسم المستخدم الأول هو `admin`. كلمة المرور هي قيمة `DEMO_PASSWORD` التي أنشأها Render تلقائيًا، وتجدها في إعدادات الخدمة ضمن **Environment**. جميع حسابات البيانات التجريبية تستخدم كلمة المرور نفسها.
5. تحقق من `https://YOUR-VERCEL-DOMAIN/api/meta`؛ يجب أن يعيد JSON. ثم سجّل الدخول من الموقع.

لا تشارك قيمة `DEMO_PASSWORD`. تُنشأ بيانات العرض مرة واحدة عند أول تشغيل؛ تغيير المتغير لاحقًا لا يغيّر كلمات مرور الحسابات التي أُنشئت مسبقًا.

## كيف ترتبط الأقسام؟

| العملية | المخزون | الحسابات (قيد مزدوج تلقائي) |
|---|---|---|
| **فاتورة بيع** | تخرج السيارة/القطعة | مدين العملاء ← دائن إيرادات + ضريبة مخرجات؛ مدين تكلفة المبيعات ← دائن المخزون |
| **استلام أمر شراء** | تدخل السيارة (برقم VIN) أو الكمية | مدين المخزون + ضريبة مدخلات ← دائن الموردين |
| **سند قبض** | — | مدين الصندوق/البنك ← دائن العملاء |
| **سند صرف** | — | مدين الموردين ← دائن الصندوق/البنك |
| **مصروف** | — | مدين المصروف + ضريبة مدخلات ← دائن الصندوق/البنك |
| **إلغاء مستند** | يُعاد المخزون | قيد عكسي (لا يُحذف أي قيد) |

## الخصوصية الإماراتية

- العملة **AED** والتاريخ الميلادي وأرقام لاتينية؛ ضريبة القيمة المضافة **5%** (قابلة للضبط) وبيع التصدير **0%**.
- **الرقم الضريبي TRN** (15 رقماً) للشركة والعملاء والموردين، وفاتورة ضريبية/مبسّطة.
- التحقق من **الهوية الإماراتية** (784-YYYY-NNNNNNN-C مع خانة التحقق) ومن أرقام **الهاتف +971** ومن **رقم الشاسيه VIN**.
- الإمارات السبع، ومصروفات مثل رسوم هيئة الطرق والمواصلات والكهرباء والماء.
- ملخص ضريبة القيمة المضافة (مرجع للإقرار VAT 201) وتقدير ضريبة الشركات 9% فوق 375,000 د.إ.
