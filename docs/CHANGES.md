# شرح التعديلات (من النسخة القديمة إلى النسخة الحالية)

## ماذا وجدت في النسخة القديمة؟
1. **الخادم هيكل فارغ**: `server.js` فقط، ومجلدات `controllers/models/routes` فارغة؛ لا يوجد جدول ولا مسار API ولا قاعدة بيانات فعلية (كان مضبوطاً على MongoDB دون أي نماذج).
2. **الواجهة لا تتصل بالخادم**: لا يوجد `fetch` في أي ملف؛ كل الأرقام «بيانات تجريبية» مكتوبة داخل ملفات JavaScript، وكل صفحة تعرّف بياناتها بشكل منفصل (فاتورة المبيعات وصفحة الفواتير والحسابات تعرض أرقاماً غير متطابقة). **لا ربط حقيقي** بين المبيعات والمشتريات والمخازن والحسابات.
3. **ثغرة أمنية**: تسجيل الدخول يعمل من المتصفح، وأزرار «دخول تجريبي» تدخل بصلاحية المدير دون كلمة مرور، والدور يُختار من المتصفح.
4. **فوضى في الملفات**: 24 صفحة HTML ينسخ كل منها القائمة الجانبية وأنماط CSS داخلها، وروابط مكسورة وملفات مفقودة (`register`، `forgot-password`، صور، صفحات)، وملفات CSS/JS غير مستعملة، وملف `.env` محفوظ داخل المشروع (يحتوي بيانات اتصال) مع `node_modules` ومعلومات محرر.
5. **محتوى سعودي**: الريال (ر.س/SAR)، ضريبة 15%، هوية وطنية سعودية، مدن سعودية، `ar-SA`، هواتف +966.

## ما حذفته ولماذا
- `register.html` و`forgot-password`: إنشاء الحسابات صار من المدير فقط (نظام ERP داخلي لا يُسجَّل فيه علناً).
- ملفات CSS/JS المكررة أو غير المستخدمة، و`node_modules` و`.vscode` و`.env` الأصلي.
- ادعاءات تسويقية غير صحيحة في الصفحة الرئيسية («المئات من المعارض»، «مجاناً»).

## ملاحظة مهمة حول قاعدة البيانات
اخترت **SQLite** بدل MongoDB لأنها قاعدة علائقية مناسبة للمحاسبة (قيود وعلاقات ومعاملات ذرّية)، ولا تحتاج تثبيتاً. إن كان مطلوباً MongoDB تحديداً (مثلاً بحسب متطلبات مقرر دراسي) فمنطق الأعمال في `backend/services` منفصل عن الجداول ويمكن نقله.

## حدود معروفة
- ضريبة الشركات تقدير فقط، وملخص VAT مرجعي وليس إقراراً رسمياً؛ **الفوترة الإلكترونية** الإماراتية (e-invoicing) غير مُنفَّذة.
- تُحفظ المبالغ كأعداد عشرية بدقة فلسين؛ للإنتاج الفعلي يُفضّل التخزين بالفلس (أعداد صحيحة).
- الواجهة تستخدم Font Awesome وخط Cairo من الإنترنت؛ بدون إنترنت تظهر الأيقونات فارغة لكن النظام يعمل.
